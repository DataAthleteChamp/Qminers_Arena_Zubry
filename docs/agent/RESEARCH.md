# Research contract: actual one-instrument arena

Read `competition.json`, `TEAM_START.md`, current round brief and data provenance.
Load only the relevant knowledge card/source. Earlier IMC research is inspiration,
not evidence that this anonymised recorded market has pegs, options or baskets.

1. Profile observed events, price/spread/depth, external flow, volatility and
   duration. BBO objects are individual orders; aggregate levels correctly.
2. State one mechanism, feasible horizon beyond 5 ms, data/window and expected sign.
3. Check payoff, dynamics, execution/queues, partial fills, latency, penalty and
   liquidation-based score before using a real-market formula.
4. Verify references, sections/read depth and licence. Do not execute unreviewed
   reference code or copy an unlicensed solution.
5. Predeclare baseline, change, rejection condition and trial ID. Freeze source.
6. Run the official simulator. Record failures, parameters and actual result.
7. Test chronological windows with correct book warmup/state, not naive row slices.
8. Report public-tape evidence separately from unseen private performance.

No P(win), private z-score, or paired-delta SE from one curve's `pnl_se`.
No future normalization, identities inferred from prices, public leaderboard
curve fitting, sandbox bypass or outside-team help. Ask organizers for technical
clarification. Retain discarded mechanisms behind disabled flags and commit notes.

Default budget: one question, up to three sources, 20 minutes before deciding
continue/park. Human can extend. More papers do not guarantee higher accuracy.
